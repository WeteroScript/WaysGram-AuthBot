# WaysGram AuthBot

Python Telegram bot for the WaysGram-owned account system. It provides Russian/English selection, emoji CAPTCHA, user menu, an in-bot admin panel, and a private HTTP API used by the WaysGram backend to deliver WaysGram login codes.

## Important boundaries

The bot delivers only one-time codes generated by the WaysGram backend for WaysGram accounts. It does not read incoming SMS, request Telegram login codes, or relay third-party authentication codes.

## Automatic +1 phone allocation

A random string beginning with +1 is not a real phone number and cannot receive service. The bot reserves real numbers through a configured number-provider API and validates +1 plus ten digits. The provider adapter contract used here is:

- POST {PHONE_PROVIDER_URL}/v1/numbers/reserve
- Authorization: Bearer PHONE_PROVIDER_TOKEN
- JSON request: {"country_code":"US","customer_reference":"waysgram:<telegram_user_id>"}
- JSON response: {"id":"provider-number-id","number":"+1XXXXXXXXXX"}

This is an adapter contract, not a claim that every provider implements these endpoints. A provider-specific adapter must be selected/configured. Until then, number allocation is disabled and the bot does not fabricate numbers.

## Run

Python 3.11+:

1. Install dependencies: pip install -r requirements.txt
2. Set BOT_TOKEN and the other environment variables in the hosting platform.
3. Start the worker: python bot.py

BOT_TOKEN is read only from the environment. Do not commit .env or put the bot token into source code. The bot uses long polling and starts an internal API on 0.0.0.0:8081 by default. Use a persistent disk for DATABASE_PATH; ephemeral hosting storage can be lost on restart/redeploy.

## Environment

| Variable | Purpose |
|---|---|
| BOT_TOKEN | Required Telegram bot token |
| ADMIN_ID | Admin Telegram ID; defaults to 8888957702 |
| DATABASE_PATH | SQLite path; defaults to data/waysgram_authbot.sqlite3 |
| INTERNAL_API_TOKEN | Secret used to authenticate WaysGram backend calls |
| INTERNAL_API_HOST | API bind host; defaults to 0.0.0.0 |
| INTERNAL_API_PORT | API bind port; defaults to 8081 |
| PHONE_PROVIDER_URL | Phone provider API base URL |
| PHONE_PROVIDER_TOKEN | Phone provider API bearer token |

## Internal API

All endpoints except /health require the X-Internal-Token header.

- GET /health — health check.
- POST /internal/v1/number/resolve — JSON {"number":"+1XXXXXXXXXX"}; confirms assignment and returns the linked Telegram user ID.
- POST /internal/v1/auth-code — JSON {"number":"+1XXXXXXXXXX","code":"123456","expires_in":300}; stores a short-lived WaysGram OTP and sends it to the matching bot user.

The WaysGram backend must independently verify the code and enforce rate limits. This bot is a delivery channel, not the source of truth for WaysGram accounts, Stars, Gram balances, or gifts. Those stay in the WaysGram backend database.
